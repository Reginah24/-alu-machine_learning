# Linear Algebra

This project contains Python scripts that explore basic linear algebra concepts
such as slicing arrays and manipulating matrices.

## Files

| File | Description |
|------|-------------|
| 0-slice_me_up.py | Slices a list into different parts using Python list slicing |
| 1-trim_me_down.py | Extracts the 3rd and 4th columns from a 2D matrix |

## Requirements

* Python 3.5
* Ubuntu 16.04
